# رِفاد | Rifad Home Care

هذه نسخة منظمة من ملف HTML المرجعي المرسل.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `styles.css`: تنسيقات الموقع.
- `script.js`: وظائف تبديل اللغة ونموذج الحجز.

## النشر على GitHub Pages
ارفع الملفات الثلاثة إلى جذر المستودع، ثم من Settings → Pages اختر Deploy from a branch، والفرع `main` والمجلد `/ (root)` ثم Save.

ملاحظة: نموذج الحجز يفتح واتساب لإرسال تفاصيل الطلب، ولا يخزن الطلبات في قاعدة بيانات. راجع رقم واتساب في `script.js` قبل النشر.
