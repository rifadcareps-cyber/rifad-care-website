# موقع رِفاد — ملفات البداية

هذه نسخة أولية ثنائية اللغة (العربية والإنجليزية) لموقع رِفاد للرعاية الصحية والتمريض المنزلي.

## الملفات
- `index.html`: صفحات الموقع الرئيسية ومحتوى الخدمات ونموذج طلب الزيارة.
- `styles.css`: التصميم المتجاوب للهاتف والكمبيوتر.
- `script.js`: تبديل اللغة وتجهيز طلب الزيارة لفتحه في واتساب.

## ما الذي يعمل حاليًا؟
- تصميم متجاوب.
- تبديل العربية/الإنجليزية.
- عرض الخدمات.
- نموذج طلب زيارة يفتح رسالة جاهزة في واتساب.
- روابط اتصال وواتساب.

## مهم قبل النشر
1. راجع رقم واتساب في `script.js` والمتغير `RIFAD_WHATSAPP`، وفي رابط الاتصال داخل `index.html`. الرقم الحالي مبني على الرقم الذي زُوّد سابقًا: `0567028862`، بصيغة دولية للرابط.
2. راجع نطاق الخدمة الفعلي والخدمات التي يمكن تقديمها، ولا تنشر خدمة غير متاحة أو غير مرخصة.
3. الأسعار ليست مدرجة عمدًا؛ أضف أسعارًا مؤكدة فقط بعد اعتمادها.
4. صورة الواجهة تستخدم رابطًا خارجيًا من Unsplash، لذا يلزم اتصال بالإنترنت لعرضها.
5. نموذج الحجز لا يخزن الطلبات في قاعدة بيانات. إنه يجهز رسالة ويرسلها المستخدم يدويًا عبر واتساب بعد الضغط على زر الإرسال.
6. لا تضع بيانات صحية حساسة أو ملفات مرضى في نسخة ثابتة من الموقع.

## النشر مجانًا عبر GitHub Pages
1. أنشئ حسابًا على https://github.com إذا لم يكن لديك حساب.
2. أنشئ مستودعًا جديدًا (New repository)، مثل `rifad-care-website`.
3. ارفع الملفات الثلاثة `index.html` و`styles.css` و`script.js` إلى جذر المستودع.
4. افتح Settings ثم Pages.
5. اختر النشر من `Deploy from a branch`، وحدد `main` والمجلد `/ (root)`، ثم Save.
6. انتظر حتى يظهر رابط النشر في صفحة Pages.
7. جرّب الموقع من هاتفك وكمبيوترك قبل مشاركة الرابط.

## ربط نطاق rifad-care.ps لاحقًا
بعد تسجيل النطاق، افتح Settings → Pages → Custom domain وأدخل `www.rifad-care.ps` ثم اتبع تعليمات DNS التي يعرضها GitHub. قد يستغرق تحديث DNS وقتًا. لا تغيّر سجلات DNS عشوائيًا، وتأكد من الاحتفاظ بسجلات البريد إن كان لديك بريد مرتبط بالنطاق.

## المرحلة التالية: إدارة الطلبات والعملاء
لأن GitHub Pages يستضيف ملفات ثابتة فقط، فإن إدارة الطلبات عبر عدة أجهزة تتطلب خدمة خلفية أو نموذجًا خارجيًا مثل Google Forms/Sheets أو قاعدة بيانات مستضافة. لا تستخدم ملفًا محليًا أو لوحة إدارة مكشوفة لحفظ بيانات المرضى. قبل إضافة تخزين بيانات، حدد صلاحيات الوصول وسياسة الاحتفاظ والخصوصية.
