# رِفاد | RIFAD Home Care

موقع رِفاد للرعاية الصحية والتمريض المنزلي.

## الملفات

- `index.html`: الصفحة الرئيسية.
- `styles.css`: تنسيقات الموقع.
- `script.js`: وظائف الموقع.

## نشر الموقع

1. ارفع الملفات إلى المستودع على GitHub.
2. افتح Settings.
3. اختر Pages.
4. ضمن Build and deployment، اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)`.
6. اضغط Save.

بعد اكتمال النشر، سيظهر رابط الموقع في إعدادات Pages.

## ملاحظة

يجب اختبار نموذج الحجز وروابط واتساب قبل استخدام الموقع مع العملاء.
